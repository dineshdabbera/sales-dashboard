# sales-dashboard
# 📊 Interactive Sales Dashboard

An interactive, browser-based sales analytics dashboard built using **HTML, JavaScript, and Plotly.js**.
Upload your own JSON dataset and instantly visualize key business insights.

---

## 🚀 Live Demo

👉 https://dineshdabbera.github.io/sales-dashboard/

---

## 📌 Features

* 📂 Upload JSON sales data from your local system
* 📈 Sales Trend Analysis (time-series)
* 💰 Profit vs Sales comparison
* 📦 Category-wise performance
* 🌍 Region-wise sales distribution
* 🎯 Discount vs Profit insights
* 🧊 Glassmorphism UI design (modern & responsive)

---

## 📁 Dataset Format

Your JSON file should be an array of objects like:

```json
[
  {
    "Order Date": "11/8/2016",
    "Sales": 261.96,
    "Profit": 41.91,
    "Category": "Furniture",
    "Region": "South",
    "Discount": 0
  }
]
```
